## Public API

Add:

```python
def evaluate_account_size_policy(
    account: AccountSnapshot | None,
    requested_mode: ExecutionMode | str | None = None,
    settings: AccountSizePolicySettings | None = None,
) -> AccountSizePolicyDecision:
    ...
```

Defaults:

- `supported_min_equity = 10_000.0`
- `supported_max_equity = 25_000.0`
- `tier_default_trade_loss_pct = 0.01`
- `absolute_trade_loss_pct_ceiling = 0.03`
- `requested_mode = live`

Decision rules:

- Missing, zero, or negative equity is restricted.
- Equity below `$10,000` is restricted from live trading but may remain paper/propose-only.
- Equity from `$10,000` through `$25,000` is eligible when no review/rejection condition exists.
- Equity above `$25,000` is review-required, not automatically granted higher limits.
- A configured cap above `1%` and at or below `3%` is review-required.
- A configured cap above `3%` is restricted.
